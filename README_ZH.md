一款基于 Vue 3 Composition API、PixiJS v8、TypeScript、GSAP 和 Tailwind CSS 的高保真华强买瓜梗系 Roguelike 网页游戏。华强是唯一可控角色，其他买瓜宇宙人物会作为敌人、地标压力、Boss 机制和局内事件登场。

游戏支持中文、英文、法语，覆盖 HUD、升级卡、本局目标、死亡复盘、字幕和浏览器语音合成。中文原声可以通过本地音频 manifest 接入，仓库不会内置未授权影视音频。

## 快速开始

```bash
npm install
npm run dev
```

打开 Vite 在终端输出的地址，通常是：

```text
http://127.0.0.1:5173/
```

生产检查：

```bash
npm run typecheck
npm run build
npm run preview
```

## 游戏目标

在无边界复古 CRT 市场中探索、清怪、完成地标、选择升级卡、形成流派，并击败最终 Boss：**黑心电子秤王**。

当前单局节奏如下：

| 节点 | 发生什么 |
| --- | --- |
| 开局 | 三选一本局目标，决定路线倾向和死亡复盘建议。 |
| Lv2-Lv4 | 建立生存、移动、基础伤害或成长能力。 |
| Lv5 | 流派觉醒：火系、冰系、磁铁、脾气核心卡权重提高。 |
| Lv10 | 市场传说：稀有卡和跨流派联动更容易出现。 |
| Lv15 | 征服者前夜：最终 Boss 预告出现，但不会立刻刷出。 |
| Boss 门槛 | 必须完成 **保熟审判台** 地标，才能解锁最终 Boss。 |
| 终局 | 击败 **黑心电子秤王** 获胜。 |

地图是无边界滚动市场，没有硬墙。华强移动时，摄像机会跟随，地面、摊位、敌人和地标会围绕当前视口继续扩展。

## 操作方式

### 桌面端

| 操作 | 输入 |
| --- | --- |
| 移动 | `WASD` 或方向键 |
| 投掷砍瓜刀西瓜 | 按住 `Space`、`J`、`K` 或 `Enter` |
| 瞄准 | 键盘攻击自动瞄准最近敌人；没有敌人时使用最近移动或瞄准方向。 |
| 选择升级 | 升级弹窗出现后点击一张卡。 |
| 查看已获得卡 | 点击已获得卡片图标。 |
| 切换语言 | 使用顶部 HUD 的语言选择器。 |

### 移动端

移动端控制只会在触控或粗指针设备上显示。

| 操作 | 输入 |
| --- | --- |
| 移动 | 左侧虚拟摇杆。 |
| 投掷砍瓜刀西瓜 | 按住右侧投掷区。 |
| 瞄准 | 右侧投掷区会结合当前目标和最近移动方向。 |
| 选择升级 | 点击一张升级卡。 |
| 查看已获得卡 | 点击已获得卡片图标。 |
| 切换语言 | 使用顶部 HUD 的语言选择器。 |

画布会根据浏览器视口动态缩放。手机端建议横屏，能给小地图、卡片栏和战斗区域留出更多空间。

## HUD 布局

HUD 现在按信息优先级拆开，避免遮挡战斗视野：

| 区域 | 内容 |
| --- | --- |
| 左上角 | 华强立绘、生命、脾气、经验、等级、幸运、局外目标入口。 |
| 右上角 | 小地图和语言选择器。 |
| 小地图下方 | 已获取卡片和选中卡片详情。 |
| 左下角 | 当前生效 Buff，只在有实际影响时显示。 |
| 下中 | 当前地标/本局目标提示和操作提示。 |
| 中央 / 侧边 | Boss 阶段提示、Boss 门槛提示、里程碑爆发、字幕和升级弹窗。 |

射击提示已经从中心移开。触屏模式会直接隐藏，避免挡住战斗。

## 小地图

小地图用于快速判断方向，不是替代探索：

| 标记 | 含义 |
| --- | --- |
| 玩家箭头 | 华强位置和当前朝向/瞄准方向。 |
| 红点 | 附近敌人。 |
| 黄色或更大的点 | 精英或金属威胁。 |
| Boss 标记 | 最终 Boss 激活后的位置。 |
| 事件标记 | 当前地标方向和距离。 |

迷路时优先看事件标记和目标提示卡上的距离。

## 本局目标

每局开局会三选一本局目标，用来给玩家一个早期方向，并在死亡复盘中给出更具体的建议。

| 目标 | 推荐路线 | 奖励倾向 |
| --- | --- | --- |
| 保熟连击 | 火系 / 脾气 | 开局获得幸运和保熟概率；完成后提高暴击收益。 |
| 找茬合同 | 风险 / 成长 | 开局经验更高但受到伤害略高；完成后获得幸运和经验。 |
| 稳住摊位 | 生存 / 冰系 | 开局获得最大生命和移速；完成后获得减伤和回血。 |

本局目标完成后会显示强化徽章，让玩家明确知道奖励已经生效。

## 核心战斗

华强的武器是 **砍瓜刀西瓜**。每个投射物分为熟瓜和生瓜两种状态。

| 状态 | 颜色 | 战斗作用 |
| --- | --- | --- |
| 熟瓜 | 红色 | 暴击伤害、西瓜汁爆炸、震屏和 50ms hit-stop。 |
| 生瓜 | 绿色 | 伤害较低，但击退更强，适合拉开距离和破 Boss 护盘。 |

幸运值越高，投出熟瓜的概率越高。熟瓜也会触发火系和暴击相关构筑。

## 伤害与生存反馈

游戏会明确显示敌人和玩家受到的伤害：

| 反馈 | 作用 |
| --- | --- |
| 敌人血条 | 每个敌人头顶都有可见 HP 条。 |
| 飘字伤害 | 命中后显示普通、暴击、火焰、冰冻、碎冰等伤害数字。 |
| 玩家掉血提示 | 最近受伤会显示来源和数值，避免不知道怎么死。 |
| 死亡复盘 | 结算等级、击杀、事件、熟瓜命中、承伤、风险卡、主要死因和建议。 |

如果突然暴毙，优先看死亡复盘。它会区分接触伤害、陷阱、秤砣爆炸和 Boss 伤害。

## 脾气系统

华强命中敌人或受到伤害都会积累脾气。脾气达到 100% 后进入 **征服者模式**。

| 效果 | 结果 |
| --- | --- |
| 画面变化 | 背景变成高对比红色。 |
| 出手频率 | 投掷冷却约缩短到三分之一。 |
| 伤害 | 投射物伤害提高。 |
| 音频 / 字幕 | 触发征服音效和本地化字幕。 |

征服者模式会随时间消耗脾气，脾气降到 0 后结束。

## 流派成型

升级系统会识别路线。火系、冰系、磁铁、脾气是主要流派，并有可见成型节点：

| 数量 | 阶段 | 结果 |
| --- | --- | --- |
| 同一流派 2 张卡 | 成型 | 路线获得第一层稳定身份和实际加成。 |
| 同一流派 3 张卡 | 质变 | 路线获得更强的终结效果。 |

当前流派效果：

| 流派 | 成型 | 质变 |
| --- | --- | --- |
| 火系 | 火伤提高，燃烧区更危险。 | 熟瓜暴击更容易引爆火焰区域。 |
| 冰系 | 减速和冰冻持续更久。 | 冰冻敌人受到额外碎裂伤害。 |
| 磁铁 | 黑洞范围和拉扯力提升。 | 金属敌人更容易被磁场碾碎。 |
| 脾气 | 脾气获取提高，出手更快。 | 征服者模式持续更有压迫。 |

HUD 会显示当前路线计数，玩家能看出自己是在开路线、已成型，还是接近质变。

## 地标：风险目标与奖励

地标是当前局内事件系统。它们会刷新在可探索市场里，提供短目标和风险收益选择。

| 地标 | 完成方式 | 风险 | 奖励 |
| --- | --- | --- | --- |
| 电子秤仓库 | 用投射物打爆核心假秤。 | 金属敌人聚集，秤砣可能堵路。 | 大量经验、磁场徽章，并强化一张磁铁或当前路线卡。 |
| 瓜摊补给站 | 走到发光补给摊位上。 | 补给会暴露位置，附近敌人更快聚集。 | 回血、幸运和提高容错的瓜摊徽章。 |
| 市场后巷 | 进入后巷并坚持到倒计时结束。 | 敌人从多方向刷新，撤退路线被压缩。 | 大量经验、脾气和 12 秒临时爆发。 |
| 保熟审判台 | 进入计时区域并坚持到倒计时结束。 | 受伤不再阻止 Boss 解锁，但结束生命百分比会降低奖励。 | 100% 生命可获得稀有语音、卡片强化、更多经验和幸运。 |

同一时间只会存在一个地标。目标提示卡会显示标题、距离、风险、奖励和完成状态。

审判台奖励按照倒计时结束时的华强生命百分比结算：

| 结束生命 | Boss 解锁 | 奖励 |
| --- | --- | --- |
| 100% | 是 | 满额奖励：稀有语音、必定强化已持有卡、最多经验、最多幸运。 |
| 80%-99% | 是 | 85% 奖励：经验/幸运降低，不触发完美专属稀有奖励。 |
| 50%-79% | 是 | 60% 奖励：普通通过奖励。 |
| 1%-49% | 是 | 30% 奖励：只保留低保奖励。 |
| 死亡 / 倒计时未完成 | 否 | 无奖励。 |

## Boss 流程

最终 Boss 被刻意设计成有仪式感的流程：

1. 达到 **Lv15**，触发征服者前夜和 Boss 警告。
2. 找到 **保熟审判台**，坚持到倒计时结束。
3. **黑心电子秤王** 解锁并进入地图。
4. 观察小地图和 Boss 阶段提示。
5. 使用生瓜击退、冰冻或硬直压力破护盘。
6. 击败 Boss 后本局胜利。

现在不再要求无伤才能开启 Boss。满血只决定额外奖励是否拿满。Boss 阶段会逐步加入护盘、召唤、陷阱、磁铁压力和燃烧区。阶段提示会让变化更明显。

## 敌人类型

| 敌人 | 作用 |
| --- | --- |
| 瓜摊老板 | Lv3 后丢假价牌陷阱，限制安全地面。 |
| 市场打手 | Lv5 后会冲刺，惩罚固定走位。 |
| 秤砣怪 | 金属敌人，会被磁铁影响；Lv10 后接近华强会蓄力爆炸。 |
| 电子秤 Boss | 中期 Boss，血量高，会放陷阱并召唤混合敌人。 |
| 黑心电子秤王 | 最终 Boss，拥有阶段、护盘、陷阱、召唤和战场压力。 |

敌人的血量、伤害、速度、刷新压力和精英概率会随华强等级提高。当前设计目标是适度组合压力，而不是让玩家完全逃不出去。

## 视觉风格

| 系统 | 实现 |
| --- | --- |
| CRT 风格 | 扫描线、色差、暗角和 2003 电视剧感调色。 |
| 像素人物 | 华强、瓜摊老板、打手、秤砣怪、电子秤 Boss 都有代码生成像素立绘。 |

## 技术架构

| 模块 | 说明 |
| --- | --- |
| 前端 | Vue 3 Composition API 单文件组件。 |
| 渲染 | PixiJS v8 `Application`、世界容器、`ResizeObserver` 自适应和 ticker 循环。 |
| 状态 | reactive/ref 管理生命、脾气、经验、等级、幸运、本局目标、Buff 和 HUD 数据。 |
| 实体 | 基于类的 `Player`、`Enemy`、`Projectile` 契约。 |
| 对象池 | 投射物和敌人使用对象池，减少高频战斗 GC 压力。 |
| 碰撞 | 运行时处理投射物命中、敌人接触、陷阱、燃烧区、磁铁吸附等。 |
| Vue-Pixi 桥接 | Pixi 负责模拟和世界渲染；Vue 负责 HUD、弹窗、语言、卡片栏、目标和复盘。 |
| 清理 | `onUnmounted` 销毁 Pixi app、移除事件监听、断开 observer，并关闭音频资源。 |
